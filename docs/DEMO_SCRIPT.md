# สคริปต์คลิปสาธิต (งานข้อ 3)

> ความยาวแนะนำ 8–12 นาที · อัดหน้าจอด้วย **OBS Studio** หรือ **Xbox Game Bar (กด Win + G)** บน Windows
> แนะนำ: แบ่งให้สมาชิกแต่ละคนพากย์คนละช่วง แล้วนำมาต่อกันใน CapCut / Canva

## เตรียมก่อนอัด
1. เปิดแอปจากลิงก์ GitHub Pages (หรือ `index.html`) ใช้หน้าต่างเบราว์เซอร์แบบ **ไม่ระบุตัวตน** เพื่อให้ข้อมูลเริ่มต้นสะอาด
2. เปิดเสียงลำโพง (มีเสียงระนาดและเสียงอ่าน)
3. รหัสบทบาทสาธิต: ครู `1111` · ผู้ดูแลระบบ `9999` (แก้ได้ใน `js/config.js`)

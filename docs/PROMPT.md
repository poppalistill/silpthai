# Prompt ที่ใช้สร้างแอป "ศิลป์ไทย (SilpThai)"

> เอกสารนี้ใช้ส่งงานข้อ 2: **Prompt ต้องกำหนดการทำงานตามแผน มีคุณสมบัติ และกำหนดผู้ใช้งาน**
> เครื่องมือ AI ที่ใช้: **Claude Code (Claude Opus 5.5)** — สร้างโค้ด ทดสอบในเบราว์เซอร์ และเขียนเอกสาร

---

## 1. Prompt หลัก (ฉบับเต็ม ใช้สั่ง AI)

```text
บทบาท: คุณคือนักพัฒนา Web Application และนักออกแบบ UX ที่เชี่ยวชาญศิลปวัฒนธรรมไทย

เป้าหมาย: สร้าง Application ชื่อ "ศิลป์ไทย (SilpThai)" เพื่อ "เรียนรู้ อนุรักษ์ และสืบสานศิลปวัฒนธรรมไทย"
ใช้งานได้จริงทั้งบนคอมพิวเตอร์และมือถือ ติดตั้งเป็นแอปบนมือถือได้ (PWA) และใช้งานออฟไลน์ได้

ผู้ใช้งาน (User Roles) — ต้องมีระบบเลือกบทบาทและสิทธิ์ต่างกัน:
1. ผู้เยี่ยมชม (Guest)        : อ่านเนื้อหา ค้นหา เล่นเกมได้ แต่บันทึกคะแนน/รายการโปรด/จองไม่ได้
2. นักเรียน/นักศึกษา          : เรียนรู้ ทำแบบทดสอบ สะสมคะแนนและเหรียญรางวัล
3. นักท่องเที่ยว              : ค้นหาเทศกาล อาหาร มารยาทไทย และจองเวิร์กช็อป
4. ประชาชนทั่วไป             : ใช้บริการทุกอย่างของสมาชิก
5. ครู/อาจารย์ (ต้องใช้รหัส)  : ดูผลคะแนนแบบทดสอบของผู้เรียนทุกคน ดาวน์โหลด CSV
6. ผู้ดูแลระบบ (ต้องใช้รหัส)  : จัดการกิจกรรม ผู้ใช้ การจอง สำรอง/นำเข้า/รีเซ็ตข้อมูล

บริการ (อย่างน้อย 15 บริการ) — ทำให้ครบทุกข้อ:
 1. สมาชิกและบทบาทผู้ใช้ (เข้าสู่ระบบ เลือกบทบาท รหัสยืนยันสำหรับครู/แอดมิน)
 2. หน้าหลัก/แดชบอร์ด (ทักทายตามเวลา สถิติ ประเพณีเดือนนี้ สำนวนวันนี้ กิจกรรมถัดไป)
 3. ค้นหาอัจฉริยะข้ามทุกบริการ (พิมพ์ หรือค้นหาด้วยเสียงภาษาไทย)
 4. แชทบอท "น้องมาลัย" ตอบคำถามวัฒนธรรมไทยจากฐานข้อมูลในแอป
 5. คลังศิลปกรรมไทย (จิตรกรรม สถาปัตยกรรม ประติมากรรม ประณีตศิลป์)
 6. นาฏศิลป์ไทย (โขน ละคร รำ ฟ้อน การแสดงพื้นบ้าน)
 7. ดนตรีไทย + ระนาดเอกเสมือนจริง 21 ลูก เล่นได้ด้วยเมาส์/นิ้ว/คีย์บอร์ด
 8. ปฏิทินประเพณีไทย 12 เดือน (ไฮไลต์เดือนปัจจุบัน)
 9. วัฒนธรรม 4 ภาค + ฝึกฟังภาษาถิ่น + ตารางเปรียบเทียบ
10. อาหารไทย พร้อมวัตถุดิบและวิธีทำโดยย่อ
11. ชุดไทย (ชุดไทยพระราชนิยม 8 แบบ และผ้าพื้นถิ่น)
12. วรรณคดีไทย
13. คลังสำนวนไทย + สำนวนวันนี้ + บัตรคำพลิกทาย
14. มารยาทไทย (การไหว้ 3 ระดับ การกราบ มารยาทในวัด)
15. ภูมิปัญญาและหัตถกรรมไทย
16. ฝึกเขียนพยัญชนะ 44 ตัวและเลขไทย ลากเส้นตามแบบ ระบบตรวจให้คะแนนอัตโนมัติ
17. ระบายสีลายไทย (ประจำยาม ดอกพิกุล กระจัง) บันทึกเป็นไฟล์ PNG และแกลเลอรี
18. แบบทดสอบความรู้ สุ่ม 10 ข้อ จับเวลา เฉลยทันที ตารางอันดับ
19. กิจกรรมและจองเวิร์กช็อป (ตรวจที่นั่งคงเหลือ ออกรหัสการจอง ยกเลิกได้)
20. รายการโปรด
21. ตั้งค่าและการเข้าถึง (โหมดมืด ขนาดตัวอักษร ความเร็วเสียงอ่าน ติดตั้งแอป)
22. ระบบผู้ดูแล (สถิติ เพิ่ม/ลบกิจกรรม รายการจอง จัดการผู้ใช้ สำรองข้อมูล)
23. เกี่ยวกับแอปและผู้จัดทำ
+ คุณสมบัติร่วม: อ่านออกเสียงภาษาไทย (TTS) ทุกหน้ารายละเอียด, ปุ่มแชร์ลิงก์,
  ระบบคะแนน/ระดับ/เหรียญรางวัล 10 เหรียญ, ใช้งานออฟไลน์ (PWA)

แผนการทำงาน (ทำตามลำดับ และรายงานผลแต่ละขั้น):
 ขั้นที่ 1 ออกแบบโครงสร้าง: แกนกลาง (router, storage, ระบบผู้ใช้, UI helper) + 1 ไฟล์ต่อ 1 บริการ
 ขั้นที่ 2 สร้างหน้าตาและธีมแบบ "สมุดศิลป์": จัดหน้าเหมือนหนังสือ กระดาษสีงาช้าง แดงชาดเป็นสีเน้นสีเดียว
          หัวเรื่อง Noto Serif Thai เนื้อความ IBM Plex Sans Thai ลำดับด้วยเลขไทย ใช้ลายประจำยามเป็นตัวคั่น
          ห้ามใช้อีโมจิตกแต่ง ห้ามไล่สีและเงาหนา รองรับมือถือ
 ขั้นที่ 3 สร้างบริการเนื้อหา (ข้อ 5–15) พร้อมข้อมูลจริงที่ถูกต้อง
 ขั้นที่ 4 สร้างบริการโต้ตอบ (ข้อ 16–19) และระบบคะแนน/เหรียญ
 ขั้นที่ 5 สร้างระบบบัญชี สิทธิ์ตามบทบาท และระบบผู้ดูแล
 ขั้นที่ 6 ทดสอบทุกหน้าในเบราว์เซอร์ (เดสก์ท็อปและมือถือ) แก้บั๊ก
 ขั้นที่ 7 เขียนเอกสาร README, คู่มือทำงานร่วมกันบน GitHub, สคริปต์คลิปสาธิต

ข้อกำหนดทางเทคนิค:
- HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้ง/build เปิดไฟล์ได้ทันที เพื่อนในกลุ่มแก้ไขง่าย
- เก็บข้อมูลใน localStorage ไม่ส่งข้อมูลส่วนตัวออกนอกเครื่อง
- ทุกไฟล์มีคอมเมนต์ภาษาไทยอธิบายวิธีเพิ่มเนื้อหา
- เผยแพร่ฟรีบน GitHub Pages
- เนื้อหาต้องถูกต้อง ระบุปีที่ยูเนสโกขึ้นทะเบียนให้ถูก ห้ามแต่งข้อมูลขึ้นเอง
```

## 3. แผนผังการทำงานของแอป (Flow)

```
เปิดแอป ──► หน้าหลัก (ผู้เยี่ยมชม)
              │
              ├─► เรียนรู้ (ข้อ 5–15) ─► เปิดรายละเอียด ─► 🔊 ฟัง / ❤️ โปรด / 🔗 แชร์ ─► +2 คะแนน
              ├─► ลงมือทำ (ข้อ 16–18) ─► ฝึกเขียน / ระบายสี / ระนาด / แบบทดสอบ ─► คะแนน + เหรียญ
              ├─► ค้นหา / น้องมาลัย ─► ไปยังเนื้อหาที่เกี่ยวข้อง
              └─► กิจกรรม ─► จอง ─► (ยังไม่เข้าสู่ระบบ) ─► หน้าสมาชิก ─► เลือกบทบาท
                                                              │
                         ┌────────────────────────────────────┼─────────────────────────┐
                    สมาชิกทั่วไป                           ครู (รหัส)                แอดมิน (รหัส)
                 จอง / โปรด / คะแนน                   + ดูผลคะแนนทุกคน        + จัดการกิจกรรม/ผู้ใช้/ข้อมูล
```

## ▶️ วิธีเปิดแอป

**แบบง่ายที่สุด:** ดับเบิลคลิก `index.html` (ทุกอย่างทำงาน ยกเว้นโหมดออฟไลน์/ติดตั้งแอป)

**แบบเซิร์ฟเวอร์ในเครื่อง** (เหมือนของจริง 100%):
```bash

```
แล้วเปิด http://localhost:5500 — หรือใช้ส่วนขยาย **Live Server** ใน VS Code (คลิกขวา index.html → Open with Live Server)

**ใช้งานจริงบนอินเทอร์เน็ต:** เปิด GitHub Pages (ดูหัวข้อด้านล่าง) จะได้ลิงก์ **https://poppalistill.github.io/silpthai/** ส่งให้อาจารย์และเปิดบนมือถือได้

## 👥 วิธีทำงานร่วมกันในกลุ่ม (GitHub)

### หัวหน้ากลุ่ม (ทำครั้งเดียว)
1. สมัคร/เข้าสู่ระบบ https://github.com → กด **New repository** ตั้งชื่อ เช่น `silpthai` → เลือก **Public** → Create (ไม่ต้องติ๊ก README)
2. ในโฟลเดอร์โปรเจกต์ รันคำสั่ง (ทำไปแล้ว):
   ```bash
   git remote add origin https://github.com/poppalistill/silpthai.git
   git push -u origin main
   ```
3. เชิญเพื่อน: repo → **Settings → Collaborators → Add people** → ใส่ชื่อบัญชี GitHub ของเพื่อน
4. เปิดเว็บใช้งานจริง: **Settings → Pages → Branch: `main` / root → Save** รอ 1–2 นาทีจะได้ลิงก์

### เพื่อนในกลุ่ม
1. ติดตั้ง [Git](https://git-scm.com) และ [VS Code](https://code.visualstudio.com) (หรือใช้ [GitHub Desktop](https://desktop.github.com) แบบไม่ต้องพิมพ์คำสั่ง)
2. รับคำเชิญทางอีเมล แล้วดาวน์โหลดโปรเจกต์:
   ```bash
   git clone https://github.com/poppalistill/silpthai.git
   ```
3. **ทุกครั้งก่อนเริ่มแก้** ดึงงานล่าสุดของเพื่อน:
   ```bash
   git pull
   ```
4. แก้เสร็จแล้วส่งขึ้น GitHub:
   ```bash
   git add .
   git commit -m "เพิ่มเนื้อหาอาหารภาคใต้"
   git push
   ```

> 💡 **แก้ไขผ่านเว็บก็ได้** — เปิดไฟล์ใน github.com แล้วกดรูปดินสอ ✏️ แก้แล้วกด Commit changes (เหมาะกับเพื่อนที่ไม่ได้ติดตั้งโปรแกรม)
> หรือกดปุ่ม `.` บนหน้า repo เพื่อเปิด VS Code บนเว็บ

### กติกาเพื่อไม่ให้งานชนกัน
- **แบ่งงานตามไฟล์** — แต่ละคนรับผิดชอบไฟล์ใน `js/modules/` ของตัวเอง (ดูตารางบริการด้านบน)
- `core.js`, `app.js`, `style.css` ให้หัวหน้ากลุ่มหรือคนเดียวเป็นคนแก้ หรือแจ้งในกลุ่มก่อน
- `git pull` ก่อนเริ่มงานทุกครั้ง และ `push` บ่อย ๆ
- ถ้าเจอ **conflict**: เปิดไฟล์ใน VS Code จะเห็นปุ่ม *Accept Current / Incoming / Both* เลือกให้ถูกแล้ว commit ใหม่

## ✏️ วิธีแก้ไข/เพิ่มเนื้อหา (ไม่ต้องเก่งโค้ด)

### เพิ่มเรื่องใหม่ในบริการที่มีอยู่
เปิดไฟล์ เช่น `js/modules/food.js` คัดลอก 1 ก้อน `{ ... },` แล้วแก้ค่า:
```js
{ id: 'kanom-krok', cat: 'ขนมไทย', emoji: '🥞', title: 'ขนมครก', sub: 'ขนมหวานจากกะทิ', tags: ['ขนม'],
  body: `<p>คำอธิบาย...</p>` },
```
- `id` ห้ามซ้ำกับเรื่องอื่นในไฟล์เดียวกัน (ใช้ภาษาอังกฤษ ไม่มีช่องว่าง)
- `cat` คือหมวด จะกลายเป็นปุ่มกรองให้อัตโนมัติ
- เนื้อหาใหม่จะค้นหาได้ และแชทบอทตอบได้ทันที

### เพิ่มข้อสอบ
ใน `js/modules/quiz.js` เพิ่มบรรทัดใน `BANK`:
```js
['คำถาม', ['ตัวเลือก ก', 'ตัวเลือก ข', 'ตัวเลือก ค', 'ตัวเลือก ง'], 1, 'คำอธิบายเฉลย'],
```
(เลข `1` คือคำตอบที่ถูก นับจาก 0 → ข้อนี้ตอบ "ตัวเลือก ข")

### เพิ่มบริการใหม่ทั้งหน้า
1. สร้างไฟล์ `js/modules/ชื่อ.js`:
   ```js
   App.register({
     id: 'games', no: 24, title: 'การละเล่นไทย', icon: '🪀', group: 'learn',
     color: '#2f6b4f', desc: 'คำอธิบายสั้น ๆ',
     items: [ /* เนื้อหาเหมือนด้านบน */ ],
     render(el, param) { App.ui.listPage(this, el, param); }
   });
   ```
2. เพิ่ม `<script src="js/modules/ชื่อ.js"></script>` ใน `index.html` (ก่อน `app.js`)
3. เพิ่มชื่อไฟล์ใน `sw.js` และเปลี่ยน `CACHE` เป็น `silpthai-v2`

### แก้ชื่อสมาชิกกลุ่ม
แก้ที่ `js/config.js` → `members`
